# Cyber Fortress Technologies — CCRA-GP 2026 Academy

**Branded, integrated certification platform candidate for controlled pilot testing.**

This package includes the premium public website, official CyFort logo and certification advert; a Google Apps Script backend; eight course modules with 24 lessons and 40 graded quiz questions; four interactive industry risk-governance labs with 20 case analyses; private student progress records; manual capstone review; certificate PDF creation and public certificate verification.

**IMPORTANT:** This ZIP is a deployable *source package*, not a live connected service. Google Forms, bank details, Google Sheets, Google Apps Script deployment, email authorization, admin approvals and GitHub Pages must be configured and tested by the owner. Do not publish the private backend, Google Sheets or any secrets to a public GitHub repository.

Read **docs/COMPLETE_SETUP_AND_TESTING.md** before deployment, and **SECURITY.md** before handling student data. A provider-issued certificate is not external accreditation.

The risk labs are interactive, evidence-based *simulations*, not actual cloud infrastructure or penetration-testing virtual machines. Assessment records are saved server-side only after successful learner authentication.
